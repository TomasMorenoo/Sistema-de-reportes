# 🎫 Sistema de Reportes con Bot de Telegram

Sistema de gestión de tickets de soporte técnico con integración a **Telegram**, desarrollado durante mi trabajo en la **Cámara Nacional Electoral**. Permite cargar, actualizar y cerrar tickets directamente desde el chat, sin necesidad de acceder a ningún panel web.

> Proyecto desarrollado por iniciativa propia en el entorno laboral.

---

## 💡 Origen del proyecto

El equipo de soporte necesitaba una forma rápida de registrar y hacer seguimiento de los problemas reportados por los usuarios. En lugar de usar papel o planillas, desarrollé un sistema conectado a Telegram para que cualquier miembro del equipo pudiera operar desde el celular en tiempo real.

---

## ✨ Funcionalidades

- 📥 **Cargar tickets** desde Telegram con descripción del problema.
- 🔄 **Actualizar el estado** de un ticket existente.
- ✅ **Cerrar tickets** una vez resueltos.
- 🌐 **Panel web** para visualizar y gestionar todos los tickets.
- 🗄️ Base de datos **SQLite** para persistencia de los reportes.
